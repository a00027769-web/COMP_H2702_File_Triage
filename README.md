## Project Overview

I created a Python program that analyses safe sample files using SHA-256 hashing. The program compares the calculated hashes with a reference CSV file, identifies known and unknown files, detects duplicate files, and saves the results in a CSV report.

## Requirements

- Python 3
- No third-party Python packages required
- Python built-in libraries: `os`, `sys`, `csv`, `hashlib`, `datetime`

## Project Files

- `file_triage.py` – Main Python program.
- `hashes_reference.csv` – Reference SHA-256 hashes.
- `sample_a.txt` to `sample_e.bin` – Five safe sample files.
- `README.txt` – Original dataset instructions.
- `triage_report.csv` – Example output generated by the program.

## How to Run

1. Download the repository files into one folder.
2. Open that folder in VS Code.
3. Open a terminal.
4. Run:

```bash
python file_triage.py
```

To analyse another folder, run:

```bash
python file_triage.py folder_path
```

Replace `folder_path` with the path to a safe folder containing `.txt` or `.bin` files.

## How the Program Works

1. The program reads SHA-256 reference hashes from `hashes_reference.csv`.
2. It finds `.txt` and `.bin` files in the selected folder, excluding `README.txt`.
3. It calculates the SHA-256 hash of each file.
4. It records the filename, extension, size and last-modified time.
5. It compares each hash with the reference list.
6. It identifies files with identical hashes.
7. It displays the results and saves them to `triage_report.csv`.

## Results

- 5 files analysed.
- 3 KNOWN files.
- 2 UNKNOWN files.
- 1 duplicate pair: `sample_a.txt` and `sample_b.txt`.

The duplicate files had identical SHA-256 hashes.

## Cybersecurity Relevance

SHA-256 hashing helps security analysts compare files and identify identical content.

A KNOWN result means the file's hash matches an entry in the supplied reference list. An UNKNOWN result means there is no matching reference entry.

An unknown hash does not automatically mean a file is malicious. A hash match also does not prove that a file is safe.

## Limitations

- The program currently analyses `.txt` and `.bin` files.
- It does not examine what a file does when executed.
- It uses the supplied reference list rather than a live threat-intelligence service.
- It is intended for safe file-triage exercises, not malware execution or analysis.
